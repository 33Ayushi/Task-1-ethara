1. Project Overview

StockPulse India is a full-stack web platform for Indian stock market analysis. Users can search for stocks listed on NSE/BSE, view real-time price data, analyze charts, track a personal watchlist, read AI-powered market news, and analyze their investment portfolio.

🎯 What problem does it solve?

Retail investors in India often use multiple apps to check prices, read news, track portfolios, and analyze trends. StockPulse India combines all these into one clean, fast, dark-themed dashboard.

🔒 Why are API routes server-side?

The Alpha Vantage API key is stored in .env.local and ONLY accessed inside Next.js API routes (/app/api/...). This means the key is never exposed to the browser — a critical security practice.

Data Flow

  1. User visits a page (e.g., /analysis?symbol=TCS)
  2. React component calls fetchStockQuote('TCS') from alphaVantage.ts
  3. alphaVantage.ts calls fetch('/api/quote/TCS') (our own server)
  4. The Next.js API route at /app/api/quote/[symbol]/route.ts calls Alpha Vantage with the secret key
  5. Alpha Vantage returns JSON → API route parses it → sends clean data to frontend
  6. If Alpha Vantage fails or rate-limits, alphaVantage.ts falls back to mock data
  7. Component receives data → renders chart, price, stats

6. Alpha Vantage API Integration

Alpha Vantage provides free stock market data. The free tier allows 25 API calls per day.

API Endpoints Used

AV FunctionOur RoutePurpose

TIME_SERIES_DAILY/api/history/[symbol]Historical OHLCV data
SYMBOL_SEARCH/api/searchFind stocks by keyword
NEWS_SENTIMENT/api/newsLatest news with AI sentiment

Indian Stock Symbol Format

Alpha Vantage uses .BSE suffix for Indian stocks. So TCS becomes TCS.BSE, and RELIANCE becomes RELIANCE.BSE. Our API routes add this suffix automatically.

Smart Fallback System

If Alpha Vantage returns an error or rate-limits:

// src/lib/alphaVantage.ts
export async function fetchStockQuote(symbol: string) {
  try {
    const res = await fetch(`/api/quote/${symbol}`);
    if (!res.ok) throw new Error();
    return await res.json(); // ✅ Real data
  } catch {
    return mock.getStockQuote(symbol); // 🔄 Fallback to mock
  }
}

8. Key Features (Technical Details)

AI Trend Analysis Logic

The trend analysis is computed in stockService.ts → getTrendAnalysis()

// Simplified version of the trend logic
function getTrendAnalysis(symbol, history) {
  // Calculate 20-day and 50-day Moving Averages
  const ma20 = average(history.slice(-20).map(d => d.close));
  const ma50 = average(history.slice(-50).map(d => d.close));
  
  // Calculate RSI (Relative Strength Index)
  const rsi = calculateRSI(history.slice(-14));
  
  // Count bullish vs bearish signals
  let bullish = 0, bearish = 0;
  if (currentPrice > ma20) bullish++;  else bearish++;
  if (currentPrice > ma50) bullish++;  else bearish++;
  if (ma20 > ma50) bullish++;          else bearish++; // Golden/Death Cross
  if (rsi < 30) bullish++;             // Oversold = buy signal
  if (rsi > 70) bearish++;             // Overbought = sell signal
  
  return { trend: bullish > bearish ? 'Bullish' : 'Bearish', confidence };
}

10. Interview Q&A

Q: What is this project and what problem does it solve?
StockPulse India is a full-stack web application for Indian stock market analytics. It solves the problem of having to use multiple apps to check stock prices, read news, track portfolios, and analyze trends. Everything is in one platform with real-time data from Alpha Vantage API.
Q: Why did you choose Next.js over plain React?
Next.js provides: (1) API Routes — so I can keep the Alpha Vantage API key secure server-side without a separate Express backend, (2) App Router — file-based routing is cleaner, (3) Server-side rendering — better performance and SEO, (4) Built-in TypeScript and ESLint support out of the box.
Q: How did you secure the API key?
The Alpha Vantage key is stored in .env.local which is gitignored (never pushed to GitHub). It's only accessed inside Next.js API routes which run on the server — never in browser-side code. The NEXT_PUBLIC_ prefix is deliberately NOT used, which would expose it to the browser.
Q: What is the fallback mechanism and why is it important?
Alpha Vantage free tier allows only 25 requests/day. When rate-limited, the alphaVantage.ts client catches the error and returns data from stockService.ts (mock data). This means the app never shows a blank page or crash — it degrades gracefully. This is called a "fallback pattern" and is essential for production apps.
Q: How does the watchlist work without a database?
The watchlist is stored in the browser's localStorage using JSON.stringify/parse. It persists across page refreshes and browser restarts on the same browser. The limitation is it's device-specific (not synced across devices). For a production app we'd add a database (PostgreSQL/MongoDB) + user authentication.
Q: Explain the AI Trend Analysis — is it real AI?
It uses rule-based technical analysis, not machine learning. It calculates: RSI (Relative Strength Index) over 14 days, 20-day Moving Average, 50-day Moving Average. Then it counts bullish vs bearish signals (e.g., price above MA50 = bullish signal). The confidence % reflects how many signals agree. While not "AI" in the ML sense, RSI and MA crossovers are legitimate technical analysis tools used by real traders and trading algorithms.
Q: What is TypeScript and why use it?
TypeScript adds static types to JavaScript. Benefits: (1) Catch errors at compile time, not runtime, (2) Better autocomplete in editors, (3) Self-documenting code — you can see what data shape a function expects. For example, the StockQuote interface in types/stock.ts ensures every component works with the same data structure.
Q: What is Recharts and how did you use it?
Recharts is a React charting library built on D3.js. I used three chart types: (1) AreaChart — for stock price history with gradient fill, (2) BarChart — for volume analysis (coloured by up/down day), (3) PieChart — for portfolio allocation and news sentiment. Each chart uses ResponsiveContainer to auto-size to its parent.
Q: What is glassmorphism in the Navbar?
Glassmorphism is a design trend where elements look like frosted glass. In the Navbar I used: backdrop-filter: blur(12px) (blurs what's behind), background: rgba(17,24,39,0.7) (semi-transparent dark), and border: 1px solid rgba(255,255,255,0.05) (subtle white border). This gives the nav a premium, modern look.
Q: How would you scale this to production?
To scale: (1) Add PostgreSQL database with Prisma ORM — store users, watchlists, portfolios, (2) Add NextAuth.js for user authentication (Google/GitHub login), (3) Replace Alpha Vantage with a paid API like Finnhub or Bloomberg for more requests, (4) Add Redis caching to reduce API calls, (5) Deploy to Vercel (perfect for Next.js), (6) Add WebSocket for real-time price streaming.
